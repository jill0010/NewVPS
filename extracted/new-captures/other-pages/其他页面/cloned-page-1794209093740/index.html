30 分钟迁移

4 步从 AWS 迁移

大多数 AnonPort 客户在 30 分钟内完成从 AWS 的切换。快照、传输、恢复、取消 — 无 IP 绑定，迁移干净可逆。

  1. 1

    为现有服务器创建快照

    从 AWS 面板创建完整磁盘快照（或用 rsync 备份数据分区）。记录当前 IP、DNS 记录及所依赖的反向 DNS 或 PTR 条目。

  2. 2

    订购等效的 AnonPort 方案

    选择司法管辖区（不确定可使用我们的选择器）、匹配的 VPS 或独立服务器层级，并用加密货币付款。令牌即时到达，服务器 5 分钟内完成配置。

  3. 3

    恢复数据并重新配置 DNS

    通过自定义 ISO 上传快照，或从旧服务器通过 SSH rsync 传输。将 A/AAAA 记录更新至新 IP。若运行 Tor 或 VPN 服务，请重新生成密钥以切断与旧主机的关联。

  4. 4

    取消 AWS 并轮换密钥

    新服务器上线 24 小时后取消 AWS 计费。轮换所有 SSH 密钥、API 令牌或服务绑定凭证，防止旧服务器重放任何内容。

常见问题

从 AWS 切换：FAQ

01 AnonPort 和 AWS，哪个更好？

取决于你的优先级。AnonPort在纯粹的运营者隐私上更胜一筹（仅凭令牌认证，无邮箱、无电话、无姓名、无法币），覆盖7个司法管辖区，并支持AI代理购买（MCP、OpenAPI、x402）。AWS 的真正强项在于：庞大的生态系统和集成；全球 30 多个区域。请根据你的实际威胁模型选择。

02 AnonPort 比 AWS 便宜吗？

AnonPort的VPS低至$7.50/mo，专用服务器低至$48.50/mo。AWS 的入门档为"2 vCPU · 1 GB · 8 GB EBS (t4g.nano)" — 上方对比表完整展示了两家的价格全貌。多月付款周期在双方均可解锁额外折扣。

03 我能像在 AnonPort 一样用 Monero 支付 AWS 吗？

AnonPort接受包括Monero（XMR）在内的8种原生加密货币，每笔订单独立充值地址，任意币种结账。AWS 是否接受Monero？否（确切的支付通道见上方功能对比）。只用加密货币的运营者下单前务必确认。

04 从 AWS 切换需要多长时间？

单台 VPS 且数据不超过 50 GB，含 DNS 传播预计 20–30 分钟。更大工作负载与磁盘传输速度线性相关；SSH rsync 通常会使目标链路饱和。

05 IP 地址会变吗？

会。入站 IP 绑定服务（DNS A/AAAA、SPF、反向 DNS、邮件中继）需要更新。我们会在面板中记录需更改的确切记录。出站服务无需客户端变更即可正常运行。

06 切换期间可以保持 AWS 服务器运行吗？

可以 — 我们也建议这样做。新服务器上线后保留旧服务器 24–48 小时，让 DNS 缓存自然清空。确认新服务器正常处理生产流量后再取消。

07 需要重新验证身份吗？

不需要。AnonPort 在任何步骤都不收集身份信息。您的账户绑定到令牌，而非姓名或邮箱。若 AWS 要求身份证，您在我们这里注册时该关联即被丢弃。

08 子域名 SSL 证书怎么办？

DNS 指向新服务器后，通过 Let's Encrypt 或您选择的 CA 重新签发证书。大多数自动化工具栈（Caddy、Traefik、certbot）一条命令即可处理。旧证书在到期前仍有效，按自己的节奏轮换即可。
