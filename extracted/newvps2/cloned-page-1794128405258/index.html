常见问题

常见问题解答

01AnonPort是什么？

在 7 个司法管辖区提供离岸主机：VPS 和独立服务器，无需 KYC，仅限加密货币付款，自动即时部署。

02是否需要提供个人信息？

不需要。完全不需要：不要姓名、邮箱、电话或证件，仅凭令牌访问。

03接受哪些加密货币？

原生支持8种币：比特币（BTC）、门罗币（XMR）、以太坊（ETH）、泰达币（USDT，ERC-20/TRC-20）、Solana (SOL), Litecoin (LTC), TRON (TRX)。所有支付天然保护隐私——无法币，无KYC。

04交付速度如何？

VPS：5分钟内。独立服务器：15-60分钟，视配置而定。

05应该选择哪个地区？

取决于您的威胁模型。冰岛和瑞士提供最强的法律保护；摩尔多瓦和俄罗斯成本最低，且不受西方法律程序约束；荷兰拥有最好的网络互联。

06是否保留日志？

不保留。零流量日志、零连接日志、零DNS日志。全盘加密。

07这些 IP 真的干净吗？你们忽略 DMCA — 这不意味着 IP 很脏吗？

"忽略 DMCA"针对的是法律处理方式，而非网络卫生。我们整个 IPv4 资源池在分配时均经过 60+ 个实时黑名单（Spamhaus、Spamcop、Barracuda、AbuseIPDB 等）的核查，此后每六小时持续监控。若您的 IP 因他人流量被列入黑名单，我们当天免费更换。没有哪个合法托管商有理由提供脏 IP — 被列入黑名单的地址会影响所有人的使用体验。
